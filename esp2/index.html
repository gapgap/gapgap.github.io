Open with a Universal Link

After publishing the site and its AASA file, reinstall the updated debug app. Send this link to yourself in Notes or Messages, then tap it to open the fake ESP test:

https://gapgap.github.io/esp2/

Tapping from Notes or Messages tests the website-to-app association. Safari may keep links to the same domain in the browser, and typing a URL into its address bar opens the website.

The Universal Link launches the harness. The SDK then resolves the real HTTP 302 running locally inside the app.

Standalone redirect server

The companion server.py serves /esp2/redirect with HTTP 302 and the exact OneLink above in its Location header.

python3 server.py
curl -I http://127.0.0.1:8787/esp2/redirect

GitHub Pages serves this page as static HTML. It cannot run the redirect server. The in-app tests work without hosting that server. Stop the in-app listener before starting the standalone server on the same simulator/Mac port.

The repository includes AASA entries for /esp2 and /esp2/* and the app includes the gapgap.github.io Associated Domain. A full hosted ESP test still needs an HTTP redirect endpoint; GitHub Pages serves static HTML.
