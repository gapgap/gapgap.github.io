This GitHub Pages site launches the test apps. A hosted ESP test needs a real HTTPS endpoint that returns HTTP 302 to the corresponding OneLink.

Hosted ESP and Local 302 are separate

Hosted ESP passes the configured HTTPS tracking URL to the SDK. The default URLs on this GitHub Pages host do not provide a custom HTTP redirect, so the hosted test will be inconclusive until you supply a real ESP tracking URL in the app.

Local 302 is an optional SDK isolation test. It deliberately uses a loopback HTTP server inside the debug app. It does not test a redirect from this website.

Optional standalone redirect server

The companion Python server can serve both real redirects on a server you control. GitHub Pages cannot execute it.

python3 server.py
curl -I http://127.0.0.1:8787/esp2/redirect
curl -I http://127.0.0.1:8787/esp2/android/redirect

Stop the in-app iOS simulator listener before binding the same Mac port, or use --port 8788.
