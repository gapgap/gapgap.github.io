A loaded SDK and a showBanner call do not prove display. Banner detection checks the SDK’s CTA attribute and its viewport position. Confirm the actual banner visually; this check does not prove an impression was recorded or that the app opens.

If the banner does not appear

  1. Serve this page over HTTPS or a local HTTP server. Use the deployed page URL for KakaoTalk testing.
  2. In AppsFlyer, confirm an active banner and that its website URL, path, device and audience rules match this page.
  3. Check dismissal and frequency caps. Compare with a fresh browser session if you previously closed the banner.
  4. If the SDK fails, inspect browser Network requests for websdk.appsflyer.com and blocked resources. If it loads, inspect the banner creative/configuration request and response.
  5. Copy the report from KakaoTalk and from Safari/Chrome to compare. Also note whether you can see the banner and what happens when you tap it.

Reference: AppsFlyer Smart Banner integration guide.
